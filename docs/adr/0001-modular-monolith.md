# 0001. Модульный монолит, синхронный стек

**Контекст.** Три модуля работают на общих пользователях, файлах, аудите и
нормативной базе. Пользователей — десятки-сотни, разработчиков — один-два.

**Решение.** Один Python-пакет `gosdoc` (`backend/gosdoc`): модули
`docs_check`, `letters`, `tables` и общее ядро `core`. API и воркеры — один
образ, разные команды запуска. Стек синхронный: SQLAlchemy 2 + psycopg 3,
redis-py, boto3; FastAPI выполняет синхронные обработчики в пуле потоков.
Тяжёлая работа (OCR, LLM, пакетные таблицы) уходит в воркеры.

**Последствия.** Нет межсервисных контрактов и распределённых транзакций.
Один код для API, воркеров и тестов, без двух вариантов (async и sync) у
каждого клиента. Если API упрётся в пул потоков, можно перевести горячие
эндпоинты на async, не трогая домен.
