# 0010. Рецензирование DOCX в MVP — только примечания

**Контекст.** python-docx (≥ 1.2) создаёт нативные примечания Word, но не
поддерживает исправления (`w:ins`/`w:del`).

**Решение.** В MVP замечания проверки оформляются примечаниями Word, привязанными
к фрагменту. Предлагаемая правка пишется текстом в примечании.

**Последствия.** Пользователь применяет правки вручную. Режим исправлений
требует прямой работы с OOXML — отдельная задача после MVP.
