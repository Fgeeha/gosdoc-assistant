# 0006. Мультиарендность через organization_id

**Контекст.** Сейчас организация одна, позже их может стать несколько.

**Решение.** Таблица `organizations`; `organization_id` (NOT NULL) во всех
доменных таблицах: пользователи, файлы, аудит, бланки, шаблоны маппинга,
задачи. У НПА `organization_id` допускает NULL: NULL означает общий акт, иначе
ведомственный. Доступ к данным идёт через `OrgRepository`, который получает
`organization_id` текущего пользователя и добавляет фильтр в каждый запрос.
Прямые запросы к доменным таблицам мимо репозитория в коде API не
используются. Миграция создаёт организацию по умолчанию, в UI выбора
организации нет.

**Последствия.** Добавить вторую организацию — это добавить строку и
пользователей; схема и код не меняются. Row Level Security в PostgreSQL можно
включить позже как второй рубеж.
