# 0003. Собственный RAG-слой без LangChain/LlamaIndex

**Контекст.** RAG здесь — это структурный чанкинг НПА, гибридный поиск
(Elasticsearch + Milvus/Chroma, слияние RRF), один промпт с JSON-ответом и
программная проверка цитаты. Фреймворки тянут сотни транзитивных зависимостей,
их нужно проверять сканером и обновлять в закрытом контуре.

**Решение.** Пакет `rag/`: `chunker`, `indexer`, `retriever`, промпты в YAML.
Модель вызывается через общий HTTP-клиент `gosdoc.core.llm` (ADR-0008).
Векторное хранилище — интерфейс `VectorStore` с реализациями Chroma (dev) и
Milvus (prod).

**Последствия.** Каждый шаг виден и тестируется, поверхность атаки меньше.
Прототипы допустимо собирать в Langflow/Jupyter, но в прод идёт только код
из репозитория.
