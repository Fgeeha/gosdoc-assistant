# 0012. Фронтенд собирается на образе Node.js

**Контекст.** ADR-0007 собирает фронтенд в стадии с Node.js из пакетов ОС. В
`astra/ubi18` это Node.js 18.19, а Vite 8 требует 20.19+ или 22.12+: сборка
образа в контуре падала на `npm run build`.

**Решение.** Фронтенд собирается отдельной стадией на образе `NODE_IMAGE` (по
умолчанию `node:22-slim`). Из стадии в итоговый образ копируется только
статика, её отдаёт nginx из пакетов ОС; сам Node.js в образы не попадает. В
контуре `NODE_IMAGE` — копия образа в реестре контура.

`python:3.11-slim` используется в `docker-compose.dev.yml` и в dev-сборках
GitHub Actions: они публикуются в `ghcr.io` и в контур не попадают.

**Последствия.** Перед первой сборкой в контуре в его реестр нужно положить
копию образа Node.js 22 и указать её в `NODE_IMAGE`. Сборочная стадия идёт не
на сертифицированной ОС, но в итоговые образы из неё попадают только файлы
статики. Пересматривает ADR-0007 (сборка фронтенда, применение
`python:3.11-slim`).
