# 0002. Фоновые задачи на dramatiq

**Контекст.** Нужны очереди для OCR, проверки документов, генерации писем,
пакетных таблиц, индексации НПА. Брокер — RabbitMQ (услуга платформы).

**Решение.** dramatiq с `RabbitmqBroker`. Статус и результат задачи хранятся в
таблице `jobs` PostgreSQL, а не в result backend dramatiq. Регламентные задачи
запускает Airflow через API, своего планировщика в приложении нет.

**Последствия.** Меньше конфигурации и меньше неожиданного поведения, чем у
Celery: ack после выполнения, повторы с backoff по умолчанию. Для статуса задачи
не нужен ещё один сервис.
