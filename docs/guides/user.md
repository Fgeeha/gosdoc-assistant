# Руководство пользователя

ГосДок Ассистент помогает проверять документы по нормативной базе, готовить
служебные письма и переносить данные между таблицами.

> **Всё, что подготовлено автоматически, — черновик.** Система может
> ошибаться. Перед использованием проверьте каждое замечание, каждую строку
> письма и результат переноса. Ответственность за документ несёт исполнитель.

## Вход

Логин и временный пароль выдаёт администратор системы (или используется
учётная запись домена). При первом входе система попросит сменить пароль:
не короче 12 символов, буквы и цифры. После пяти неверных попыток учётная
запись блокируется на 15 минут — подождите или обратитесь к администратору.

Сменить пароль — пункт меню «Сменить пароль». После смены пароля выполняется
выход на всех устройствах.

## Проверка документа

Раздел «Проверка».

1. Нажмите «Загрузить и проверить» и выберите файл: DOCX, ODT, PDF (в том
   числе отсканированный), TXT. Можно выбрать несколько файлов.
2. Проверка идёт в фоне — состояние видно в таблице «Мои проверки».
   Отсканированные документы распознаются дольше.
3. Нажмите «Открыть», чтобы увидеть замечания:

| Отметка | Что значит |
|---|---|
| критично | ссылка на акт, утративший силу |
| внимание | ссылка на устаревшую редакцию (и изменился ли текст статьи), неверная дата акта, нет такой статьи; несоответствие содержания норме |
| к сведению | акта нет в нормативной базе — проверьте ссылку сами |

Нажмите на строку, чтобы увидеть фрагмент документа, **дословную цитату
нормы** и рекомендацию. Замечание по содержанию выдаётся только вместе с
цитатой, найденной в тексте нормы; если подтвердить вывод нормой нельзя,
система его не показывает.

Скачайте «Документ с примечаниями» — это ваш файл с примечаниями Word на
полях; предлагаемая правка написана в тексте примечания. «Отчёт DOCX» —
таблица всех замечаний.

Отметьте каждое замечание «верно» или «неверно» — это помогает улучшать
проверку.

Проверка зависит от полноты нормативной базы: если нужного акта или его
редакции в базе нет, обратитесь к администратору нормативной базы.

## Подготовка письма

Раздел «Письма».

1. Выберите тип: ответ на обращение гражданина, запрос или сопроводительное
   письмо. Бланк — встроенный по ГОСТ Р 7.0.97-2016 или бланк организации.
2. Загрузите входящее письмо (DOCX, PDF с текстом, TXT), укажите его номер и
   дату регистрации, адресата (каждая строка адреса — с новой строки) и
   кратко опишите, что нужно ответить.
3. Нажмите «Подготовить черновик». Система предложит заголовок, обращение и
   текст. Места, где не хватило сведений, помечены **[уточнить]**.
4. Отредактируйте текст и реквизиты. Абзацы разделяются пустой строкой.
   Исходящий номер и дату вводите вручную. Каждое «Сохранить новую версию»
   сохраняет версию — история видна справа.
5. Справа — проверки:
   - **срок ответа** на обращение гражданина: 30 дней со дня регистрации, при
     продлении — ещё 30 (отметка «Срок продлён»); если срок выпадает на
     выходной, он переносится на ближайший рабочий день;
   - соответствие исходящего номера маске организации;
   - **стиль**: разговорные обороты, слишком длинные предложения,
     восклицательные знаки, многоточия, неконкретные сроки («в ближайшее
     время»).
6. «Сформировать DOCX» — письмо по ГОСТ: поля, шрифт Times New Roman 14,
   реквизиты на своих местах. «Сформировать PDF» готовится в фоне —
   ссылка появится в списке версий.
7. Руководитель подразделения проверяет письмо и нажимает «Утвердить» —
   отметка «черновик» снимается, дальше письмо не редактируется. Для
   утверждения нужны исходящий номер по маске и дата.

## Перенос данных между таблицами

Раздел «Таблицы».

1. Загрузите исходные таблицы (XLSX, XLS, CSV, ODS) и целевой шаблон. В
   первой строке и источника, и шаблона должны быть заголовки колонок.
   Строка под заголовками в шаблоне задаёт оформление (шрифт, формат чисел)
   — оно будет перенесено на все строки.
2. «Предложить маппинг» — система сопоставит колонки по названиям и виду
   данных. Отметка у колонки:
   - зелёная — найдено по названию;
   - оранжевая — предложено моделью, проверьте особенно внимательно;
   - красная — источник не найден, выберите сами.

   Данные строк при этом никуда не передаются.
3. Для каждой колонки шаблона выберите, как её заполнить:

| Действие | Пример |
|---|---|
| Копировать | значение без изменений |
| Объединить колонки | «Город», «Улица» → «Москва, ул. Ленина» |
| Часть значения | «ул. Ленина д. 5», разделитель « д. », часть 2 → «5» |
| Дата | «2024-01-15», «15.01.24» → «15.01.2024» |
| Собрать ФИО | «Иванов», «Иван», «Иванович» → «Иванов Иван Иванович» или «Иванов И.И.» |
| Часть ФИО | «Иванов Иван Иванович» → «Иванов» |
| Сумма | «12 500,00 руб.» → 12500.00 |
| По справочнику | «м=Мужской; ж=Женский»; значение не из справочника — ошибка, если не задано «иначе» |
| Постоянное значение | одинаковое значение во всех строках |

4. «Проверки» у колонки: обязательное, ИНН, СНИЛС, ОГРН (по контрольной
   сумме), целое, число, дата. «Какие строки переносить» — условия отбора
   (например «Статус равно активен»).
5. «Предпросмотр» показывает результат на первых строках и причины
   отклонения.
6. «Перенести» — по одному файлу результата и отчёту на каждую исходную
   таблицу. **Ни одна строка не теряется**: каждая либо в результате, либо в
   отчёте «Не перенесено» с причиной и исходными значениями. В сводке
   отчёта: строк в источнике = перенесено + отфильтровано + отклонено.
7. Удачный маппинг сохраните как шаблон («Сохранить как шаблон маппинга»),
   при необходимости — общий для коллег. В следующий раз выберите его в
   списке «или сохранённый маппинг» и сразу запускайте перенос.

## Хранение файлов

Загруженные файлы и результаты хранятся 30 дней (срок задаёт
администратор), затем удаляются автоматически. Скачайте нужные результаты
заранее. Ваши файлы видите вы и руководитель вашего подразделения.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| «В PDF нет текстового слоя» (в письмах) | загрузите DOCX или PDF с текстом; сканы поддерживаются в проверке документов |
| «Не удалось определить вид, номер и дату акта» | в начале текста акта должна быть строка вида «Федеральный закон от ДД.ММ.ГГГГ № …» |
| «В первой строке таблицы должны быть заголовки» | уберите пустые строки и объединённые ячейки над заголовками |
| «Исходящий номер не соответствует маске» | уточните формат номера у делопроизводителя |
| Задача в состоянии «ошибка» | прочитайте текст ошибки; если он не помогает — сообщите администратору номер задачи |
